# Installation Guide

## download and install xampp

## copy examcenter extracted file to c:/xampp/htdocs/

## launch xampp

## start apache and mysql

## open xampp shell

## sign into mysql using mysql -u root -p 
- password should be left blank

## open help.txt, copy and paste the content into xampp shell and run

## app is now aavilable at 127.0.0.1/Examcenter/
